    How it works

    Four steps, every answer

    Nothing is hidden: the desktop version can replay each step live.

    1. Safety checkThe question is screened for abuse and prompt-injection tricks first.
    2. Find the factsIt searches my documents by meaning and by exact names, and keeps the best matches.
    3. Write the answerThe AI model writes a reply using only those passages, nothing invented.
    4. Show the sourcesEvery answer lists what it used. No source? It admits it doesn’t know.
